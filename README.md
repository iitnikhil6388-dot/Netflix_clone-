# 🎬 Netflix Clone

A responsive Netflix-inspired website built using **HTML, CSS, and JavaScript**.

## ✨ Features

* Netflix-style UI
* Movie/TV show sections
* Responsive design
* Search functionality
* Movie banners and posters

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
